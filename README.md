# 🎉 Event Manager

A responsive, visually polished event management web app built with HTML, CSS, JavaScript, Bootstrap, and Tailwind CSS. Designed as a front-end showcase by an aspiring AI Full Stack + MERN Developer, with future plans for backend integration and intelligent features.

---

---

## ✨ Features

- **Event Creation**: Add events with title, description, date, and invitees.
- **RSVP System**: Toggle RSVP status for each invitee.
- **Alarm Notifications**: Browser alerts for upcoming events.
- **Search Functionality**: Filter events by title in real time.
- **Responsive Layout**: Mobile-friendly card-based design.
- **Glassmorphism UI**: Frosted-glass effect for cards and forms.
- **Dark Mode Toggle**: Persistent theme switching.
- **Background Image**: Customizable with brightness overlay.

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **Bootstrap 5**
- **Tailwind CSS**
- **LocalStorage** for data persistence

---

## 🚀 How to Run Locally

1. Clone or download the repository.
2. Place your preferred background image in the root folder as `background.jpg`.
3. Open `index.html` in your browser.
4. Start creating and managing events!
